# Gestão de Atividades

Sistema completo de gestão de jornada, acordos coletivos e timesheet.

## 🚀 Acesso Rápido

Abra o arquivo `index-refatorado.html` no seu navegador.

## 📋 Funcionalidades

- ⏱️ Registro de ponto
- 📊 Dashboard com estatísticas
- 📈 Gráficos e analytics
- 📅 Gestão de eventos (férias, feriados, etc.)
- 📝 Acordos coletivos
- 💾 Backup e restauração
- 📤 Exportação Excel/PDF

## 🛠️ Hospedagem

Veja o arquivo `GUIA_HOSPEDAGEM.md` para instruções completas de como hospedar gratuitamente.
