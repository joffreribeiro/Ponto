      Backup e Restauração

      Faça backup de todos os seus dados e restaure quando necessário.

      Fazer Backup

      Baixar arquivo com todos os dados do sistema (registros, eventos, acordos, atividades).

      Restaurar Backup

      Restaurar dados a partir de um arquivo de backup anterior.

      Limpar Todos os Dados

      Remover permanentemente todos os registros, eventos e configurações. Esta ação não pode ser desfeita.

      ℹ️ Informações

      • Backups são salvos em formato JSON e podem ser abertos em qualquer editor de texto.
      • Sempre faça um backup antes de executar limpeza de dados.
      • Restaurações substituem completamente os dados atuais.
